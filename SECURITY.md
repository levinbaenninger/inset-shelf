# Reporting a vulnerability

Use GitHub's [private vulnerability report form](https://github.com/levinbaenninger/inset-shelf/security/advisories/new). Include the affected version or commit, the platform, the behavior you observed, and what data or permissions could be affected. Use a small example with dummy clipboard contents, window titles, and files.

Keep the details in the private report while maintainers investigate. For crashes and feature requests without a security impact, use the [issue tracker](https://github.com/levinbaenninger/inset-shelf/issues/new/choose).
