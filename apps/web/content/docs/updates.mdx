Public releases of Inset Shelf have version numbers such as `v0.1.15`. The download links on this site fetch the release marked **Latest**. [GitHub releases](https://github.com/levinbaenninger/inset-shelf/releases)

## How the app updates

The installed app checks for an update when it starts and every four hours. It downloads newer builds in the background and shows a notice when one is ready. Choose **Restart to Update to v…** from the menu bar icon on macOS or the tray icon on Windows. If you don't restart, the update installs when you quit.

The icon's menu also shows the running version. Choose **Check for Updates…** there to check by hand when an update isn't already in progress.

## On macOS

The Mac releases use the same self-signed certificate so an update keeps your permissions. If your build shows version 0.1.0, install the current build by hand as in [Install](/docs/install), then grant the permissions again.

## On Windows

Only the installer (`.exe`) updates itself. The portable zip copies can't; to update one, download the new zip.
