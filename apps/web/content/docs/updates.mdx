---
title: Updates and versions
description: The app never updates on its own. You check, download and restart.
---

Every build of Inset Shelf is a versioned release on [GitHub](https://github.com/levinbaenninger/inset-shelf/releases), such as `v0.1.15`. The newest one is marked **Latest**, and the download links on this site always fetch it.

## How the app updates

The app never checks for updates on its own, not at launch and not later. Until you ask, it contacts nothing. Each step is yours to take, from the menu bar icon's menu or the **Inset Shelf** menu:

1. **Check for Updates…** asks GitHub for the latest release and tells you whether there is a newer one.
2. **Download Update to v…** appears when there is. Nothing is downloaded until you choose it.
3. **Restart to Update to v…** appears once the download is done. The update installs only when you choose it; quitting the app does not install it.

The menu bar icon's menu always shows the running version.

## On macOS

Every build is signed with the same certificate, so an update keeps your permissions. A build that shows version 0.1.0 can't accept an update: install the current build by hand once, as in [Install](/docs/install), and grant the permissions again. After that it can update from the menu.

## On Windows

Only the installer (`.exe`) can update from the menu. The portable zip copies can't; to update one, download the new zip.

The Windows build isn't signed yet. Until it is, the only integrity check on an update is the SHA-512 in GitHub's release feed. Each release also publishes a `SHA256SUMS.txt` next to its files, so you can check a download by hand.
