---
title: Keyboard shortcuts
description: Every key on macOS. On Windows, Ctrl takes the place of ⌘.
---

**Keyboard Shortcuts** (`⌘/`, `Ctrl+/` on Windows) lists every key for your system in the app. On Windows the shortcuts use `Ctrl` where the Mac uses `⌘`.

## Anywhere

| Keys | What happens |
| --- | --- |
| `⇧ ⇧` with text selected | Saves the selection with where it came from. |
| `⇧ ⇧` with nothing selected | Shows or hides the shelf. |
| `⌃⌥S` (`Ctrl+Alt+S`) | Shows the shelf, or hides it when it is in front. |

## In the shelf

| Keys | What happens |
| --- | --- |
| `↑` `↓` | Move through the items. |
| `Space` | Checks the item off. |
| `Return` | Edits the item, or an image's or file's note. |
| `⌘C` | Copies it. |
| `⌥⌘C` | Copies it with its link and details. |
| `⇧⌘C` | Copies the picked items as a list. |
| `⌘O` | Opens it where it came from, or an image to draw on. |
| `→` | Opens its details. `←` or `Esc` goes back. |
| `⌥⌘↑` `⌥⌘↓` | Moves it to the section above or below. |
| `⌫` | Deletes it. `⌘Z` brings back the last deleted item. |
| `⌘F` | Searches. |
| `⌘1`–`⌘9` | Picks the section for new items. |
| `⌘D` | Adds or focuses the description. |
| `⇧⌘S` | Adds next steps. |
| `⇧⌘D` | Opens the Due picker. |
| `⇧⌘L` | New window link. |
| `⌥⌘N` | New drawing. |
| `⌘,` | Settings. |
| `Esc` | Hides the shelf. While you type, the first `Esc` clears or ends it. |

## In a drawing

| Keys       | What happens                           |
| ---------- | -------------------------------------- |
| `P`        | Pin tool.                              |
| `B`        | Pen.                                   |
| `1`–`9`    | Selects a pin.                         |
| Arrow keys | Nudge the selected pin, `⇧` for 10 px. |
| `⇧P`       | Drops a pin at the pointer.            |
| `⌘↩`       | Saves the drawing to the shelf.        |
