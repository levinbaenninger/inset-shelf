---
title: Keyboard shortcuts
description: Shortcuts for capturing, working in the shelf, and drawing.
---

Open **Keyboard Shortcuts** with `⌘/` (`Ctrl+/` on Windows) to see the keys for your system. On macOS it is also in the **Help** menu and the menu bar icon's menu. On Windows it is in the tray icon's menu. The tables below use macOS keys. On Windows, use `Ctrl` for `⌘` and `Alt` for `⌥`.

## Anywhere

| Keys | What happens |
| --- | --- |
| `⇧ ⇧` with text selected | Saves the selection with any source details the shelf can read. |
| `⇧ ⇧` again while the capture notice shows | Opens [the why field](/docs/capture#say-why) with the same selection or no selection. |
| `⇧ ⇧` with nothing selected and no capture notice | Shows or hides the shelf. |
| `⌃⌥S` (`Ctrl+Alt+S`) | Shows the shelf, or hides it when it is in front. |

## In the shelf

| Keys | What happens |
| --- | --- |
| `↑` `↓` | Move through the items. |
| `⌘N` | Focuses the note field. |
| `⇧⌘N` | Starts a new section. |
| `Space` | Checks the item off. |
| `Return` | Edits the item or its caption in place, with the caret at the end. |
| `⌘C` | Copies it. |
| `⌥⌘C` | Copies it with its link and details. |
| `⇧⌘C` | Copies the picked items, the selected item, or the current section's unchecked items as a list. |
| `⌘O` | Opens it where it came from, or an image to draw on. |
| `→` | Opens its details. `←` or `Esc` goes back. |
| `⌥⌘↑` `⌥⌘↓` | Moves it to the section above or below. |
| `⌫` | Deletes it. `⌘Z` brings back the last deleted item. |
| `⌘F` | Searches. `↓` selects the first result. |
| `⌘1`–`⌘9` | Picks the section for new items. |
| `⌘D` | Adds or focuses the description. |
| `Esc` in a field | Leaves the field and keeps the keyboard on it, so `Tab` goes on from there. `Return` types in it again. |
| `⇧⌘S` | Adds next steps. |
| `⇧⌘D` | Opens the Due picker. |
| `⇧⌘L` | New window link. |
| `⌥⌘N` | New drawing. |
| `⌘V` | Pastes a file or image as a new item in the list, or as an attachment in Details. |
| `⌘,` | Settings. `Esc` closes them. |
| `Esc` | Closes a menu, returns from Details, clears a search or selection, or hides the shelf. |

## In a drawing

| Keys        | What happens                                  |
| ----------- | --------------------------------------------- |
| `P`         | Pin tool.                                     |
| `X`         | Pen.                                          |
| `V`         | Select tool.                                  |
| `L`, `A`    | Line, arrow.                                  |
| `R`, `O`    | Rectangle, ellipse.                           |
| `T`         | Text.                                         |
| `1`–`9`     | Selects a pin.                                |
| Arrow keys  | Nudge the selected pin, `⇧` for 10 px.        |
| `⇧P`        | Drops a pin at the pointer.                   |
| `⌘D`        | Duplicates the selection.                     |
| `⌘Z`, `⇧⌘Z` | Undo, redo. On Windows, use `Ctrl+Y` to redo. |
| `⌘↩`        | Saves the drawing to the shelf.               |
