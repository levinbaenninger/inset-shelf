---
title: Linked windows
description: Keep a set of open windows with an item, and bring them all back.
---

A window link keeps a set of windows with an item, in order, so you can come back to all of them at once.

- **File > New Window Link…** (`⇧⌘L`, or **+** in the note field) opens a picker with the open windows. Pick some, and they become a note named after them, which you can retitle at once.
- **Link Window…** in an item's **Details > Add** menu adds windows to that item.

Each window keeps what the picker could read, such as a picture, app, page, or file. In Details, use **Open page**, **Open file**, or **Bring app forward** (**Open app** on Windows) as available. If there are several windows, **Reopen all** runs the open action for each one.

Click the window's description or **+ Description** to edit it. `Return` keeps the change and `Esc` restores the previous text. `⌘Z` restores a window link you removed in Details.

On macOS the picker needs the Screen & System Audio Recording permission. See [Install](/docs/install#permissions).
