# Inset Shelf

Select text in any app and tap Shift twice. Inset Shelf saves it beside the window you're working in, along with a link back to its source when available. Add screenshots, files, and notes to the same shelf, then copy or drag them into another app.

**[Download for macOS or Windows 11](https://github.com/levinbaenninger/inset-shelf/releases/latest)** · [Installation and permissions](https://inset-shelf.levexis.workers.dev/docs/install) · [User guide](https://inset-shelf.levexis.workers.dev/docs)

The Mac app and Windows installer update automatically. Your items and attachments stay on your computer.

## Development

Use [Vite+](https://viteplus.dev) to run the desktop app locally.

```sh
vp install
cd apps/desktop
vp run dev
```

See [Contributing](CONTRIBUTING.md) for the website, tests, and release process. [Report bugs and request features](https://github.com/levinbaenninger/inset-shelf/issues/new/choose) or [report a security issue privately](SECURITY.md).
